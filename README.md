## Description

Codebase is a gamified learning platform designed to teach programming using C#. It guides students from basic syntax to more advanced computer science concepts in an interactive and structured way.

## Features

- **Beginner Module**
  - Introduction to C# syntax
  - Variables, loops, conditions, and functions
  - Basic problem-solving exercises

- **Intermediate Module**
  - Algorithmic thinking and problem-solving challenges
  - Practice with structured programming concepts

- **Advanced Module**
  - Introduction to lexing (tokenization)
  - Abstract Syntax Trees (AST)
  - Building a simple transpiler from a custom language into C#

## Technical Overview

The project simulates parts of a compiler pipeline:
- Lexical analysis (token generation)
- AST construction
- Basic transpilation logic

## Goal

The goal of Codebase is to make learning programming more engaging by gradually introducing compiler concepts in a simplified and educational way.

## Future improvements

- Expand the platform with more advanced compiler features (optimization passes, better AST handling)
- Add a visual debugger for step-by-step execution of code
- Improve the transpiler to support more complex language features
- Introduce user accounts and progress tracking
- Add more interactive exercises and challenges
